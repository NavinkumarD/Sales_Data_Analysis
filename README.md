# Sales_Data_Analysis

This project analyzes retail sales data using Python in Google Colab. 
It performs data cleaning, exploratory data analysis (EDA), and visualizations to uncover insights about sales trends, top-selling products, and sales distribution by category.

## Features
- Clean and preprocess sales data
- Calculate Total Sales
- Visualize sales trends over time
- Identify top-selling products
- Visualize sales distribution by category
- Optional: Save cleaned dataset

## Dataset
- Columns: Date, Product, Category, Quantity, Price
- Can replace with any sales dataset for analysis

## How to Run
1. Open the notebook in Google Colab
2. Upload your sales CSV
3. Run all cells

## Libraries Used
- pandas
- matplotlib
- seaborn
